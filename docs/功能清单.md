# 云图图书馆 · 功能清单

> 依据当前代码（分支 `feature/optimize`）逐页整理，共 **19 个页面 / 10 个云函数 / 8 个集合**。
> 说明：「管理员」不是一个独立账号体系，而是叠加在读者身份上的一层权限——同一个微信账号，既能借书，也能进管理后台。

---

## 0. 角色模型

| 维度 | 取值 | 说明 |
|---|---|---|
| 角色 `role` | `user` / `admin` | 管理员拥有全部读者能力，另加底部「管理」Tab |
| 借书证 `card.status` | `none` 未申请 / `pending` 审批中 / `active` 已开通 / `rejected` 已驳回 | 与角色**相互独立**：管理员也要持证才能借书，但没证不影响管后台 |
| 身份获取 | 首个登录用户自动成为管理员；也可用 `ADMIN_OPENID` 环境变量或管理端「用户管理」指定 | — |

## 1. 借阅者模式（读者端）

### 1.1 账号与身份

| 功能 | 位置 | 说明 |
|---|---|---|
| 微信登录 | `pages/login/index` | 首次登录填写头像 + 昵称；老用户一键登录 |
| 编辑资料 | 我的 → 点头像 | 改头像、昵称 |
| 退出登录 | 我的 → 底部 | 清本地登录态 |
| 身份展示 | 我的 → 昵称旁标签 | 「读者 / 管理员」，管理员多一个「管理后台 ›」入口 |

### 1.2 找书（首页）

| 功能 | 说明 |
|---|---|
| 关键词搜索 | 书名 / 作者 / ISBN，回车即搜，可一键清空 |
| 馆藏地点筛选 | 「全部」+ 每个地点的「XX 可借」，按该地点实时库存过滤 |
| 图书列表 | 封面（无封面时按书名首字生成色块）、分类标签、可借状态（可借 / 借出 / 待配馆藏） |
| 多馆藏库存 | 卡片上直接显示「广州 2 · 西安 1」这类地点库存胶囊 |
| 分页 | 上拉加载，到底提示「已加载全部 N 本」 |
| 未登录引导 | 底部悬浮「登录后可在线借阅」 |

### 1.3 为你推荐

| 功能 | 说明 |
|---|---|
| 首页推荐位 | 未搜索、未筛选时显示横滑卡片（6 本）+「更多 ›」 |
| 推荐理由 | 每本一句话，如「你常借文学」「高分好评」「新书上架」 |
| 打分维度 | 分类偏好 35 + 作者偏好 15 + 热度 20 + 口碑 20 + 新书 10 |
| 过滤规则 | 排除已借过、已评论的书；同一作者最多 2 本 |
| 完整列表 | `pages/recommend/index`：继续加载 / 换一批（重新打分洗牌） |
| 冷启动 | 无借阅历史时降级为「热门 + 高分 + 新书」 |

### 1.4 图书详情

| 功能 | 说明 |
|---|---|
| 基本信息 | 书名、作者、分类、ISBN、出版社、出版年份、被借次数 |
| 馆藏分布 | 逐地点显示「可借 N 本 / 已被预约 / 暂无库存」 |
| 内容简介 | 最长 500 字，空时显示「暂无简介」 |
| 书评概览 | 平均分、评价人数、最新 2 条 + 馆员回复，「全部 N 条 · 写书评 ›」 |
| 借阅说明 | 借期、限借本数（读当前馆藏设置） |
| 底部按钮 | 立即借阅 / 暂无馆藏（待配馆藏）/ 已被借出 |

### 1.5 借阅全流程

| 环节 | 用户操作 | 系统行为 |
|---|---|---|
| 申请借阅 | 详情页「立即借阅」→ 选馆藏地点（多地点时弹出选择）→ 在日历里选**取书日期** | 只能选该地点有人值班的日期；生成 `pending` 记录，占用该书该地点的可借名额 |
| 取消申请 | 我的借阅 →「取消申请」 | 记录转 `cancelled`，释放占用 |
| 确认借出 | 由管理员线下交付后操作 | 状态转 `borrowing`，按地点扣库存、`borrowCount + 1`，应还日期 = 确认日 + 借期（默认 30 天） |
| 续借 | 我的借阅 →「申请续借」 | 受「可续借次数 / 每次延长天数」限制；已逾期或已用完次数时按钮不出现 |
| 预约还书 | 我的借阅 →「预约还书」→ 选还书日期 | 只能选值班日、不能选过去；状态转 `return_requested` |
| 取消还书申请 | 我的借阅 →「取消还书申请」 | 回到 `borrowing` |
| 确认归还 | 由管理员线下收书后操作 | 状态转 `returned`，库存回补，记录归还时间 |
| 逾期 | 系统派生 | 借出中且过应还日期 → 显示「已逾期 N 天」，列表标红 |
| 借阅记录 | 我的 →「完整借阅记录」 | 全部状态分页展示：申请时间、交付时间、应还、归还时间 |

### 1.6 借书证

| 功能 | 说明 |
|---|---|
| 申请开通 | 选归属馆藏地点 + 填手机号，提交后 `pending` |
| 状态展示 | 未申请 / 审批中 / 已开通 / 已驳回，每种状态都有说明文案 |
| 重新申请 | 被驳回后可再次提交 |
| 修改借阅地址 | 已开通时可换归属馆藏（影响可借馆藏与借还地点） |

### 1.7 书评

| 功能 | 说明 |
|---|---|
| 写 / 改书评 | 1–5 星 + 5–500 字；一人一书仅一条，再次提交即编辑（标「已编辑」） |
| 匿名发表 | 开关控制，匿名后展示「匿名读者」 |
| 点赞 | 「有用」计数，同一人可取消 |
| 删除 | 删除自己的书评 |
| 列表与排序 | 按最新 / 最有用；顶部平均分 + 1–5 星分布条形图 |
| 馆员回复 | 展示在书评下方，回复时会给作者发通知 |

### 1.8 消息与待办

| 功能 | 说明 |
|---|---|
| 通知类型 | 借阅成功、到期提醒、逾期提醒、借书证审批、系统公告、书评回复 |
| 通知操作 | 未读红点、只看未读 / 全部、全部已读、点击跳转对应页面、分页加载 |
| 通知设置 | 按类型开关；关掉后不再产生该类站内通知，历史保留；系统公告不可关 |
| 系统待办 | 自动生成：待取书、即将到期、已逾期等，点击直达对应记录 |
| 自定义待办 | 标题（≤30 字）、备注（≤200 字）、截止日期、优先级（高 / 中 / 低） |
| 待办操作 | 勾选完成 / 取消完成、删除、逾期天数提示 |
| 分组 | 系统提醒 / 我的待办 / 已完成 |

### 1.9 我的

用户卡片（头像昵称角色）、借书证状态卡、进行中借阅（含快捷还书 / 续借）、快捷入口（消息通知带未读数、我的待办、为你推荐）、完整借阅记录、退出登录。

## 2. 管理员模式（管理端）

底部「管理」Tab，非管理员进入显示「您不是管理员」+ 去登录。

### 2.1 管理首页

| 区块 | 内容 |
|---|---|
| 统计卡（5） | 馆藏图书、借出中、待确认、已逾期、注册用户；点击直达对应列表或筛选 |
| 功能入口（8） | 图书管理、借阅管理、用户管理、馆藏设置、值班管理、数据统计、发送通知、书评管理 |

### 2.2 图书管理

| 功能 | 说明 |
|---|---|
| 列表与搜索 | 书名 / 作者 / ISBN；显示各地点库存 |
| 新增图书 | ISBN、书名（必填）、作者（必填）、封面、分类、出版社、年份、简介 |
| ISBN 自动获取 | 调 `lookupBook` 云函数抓取书名 / 作者 / 出版社 / 年份 / 简介 / 封面 |
| 封面 | 拍照或相册选择、可预览、可更换 / 移除 |
| 编辑 | 改全部字段；**分地点调库存**，且不能低于当前在借数量 |
| 删除 | 二次确认 |
| 单书借阅记录 | 详情页点「被借次数」→ 该书借阅记录页，可按状态筛选、下拉刷新 |

### 2.3 借阅管理

| 功能 | 说明 |
|---|---|
| 状态页签 | 全部 / 待借出 / 借出中 / 待归还 / 逾期 / 已归还 / 已取消，**横滑胶囊 + 数量徽标**（待借出、待归还、逾期标红） |
| 确认借出 | 二次确认后扣库存、算应还日期、发订阅消息 + 站内通知 |
| 取消申请 | 管理员代用户撤销待确认申请 |
| 确认归还 | 库存回补、记录归还时间 |
| 取消还书申请 | 把 `return_requested` 打回 `borrowing` |
| 催还 | 对逾期记录手动发送逾期提醒（订阅消息 + 站内通知） |
| 筛选吸顶 | 列表滚动时页签常驻 |

### 2.4 用户管理

| 功能 | 说明 |
|---|---|
| 搜索与筛选 | 昵称搜索；全部 / 读者 / 管理员 / 借书证申请 |
| 借书证审批 | 通过、驳回（通过后写通知） |
| 角色调整 | 设为管理员、降级为读者 |
| 移除借书证 | 已开通的证可收回 |
| 自我保护 | 当前账号不可降级自己、不可移除自己的证 |
| 分页 | 上拉加载 |

### 2.5 馆藏设置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| 馆藏地点 | 广州、西安 | 增删；该地点仍有库存或未归还借阅时，保存会被拦截并回滚 |
| 借期（天） | 30 | 确认借出时按此计算应还日期 |
| 每人同时最多借阅 | 3 | 申请借阅时校验 |
| 可续借次数 | 1 | 0 表示关闭续借 |
| 每次续借延长（天） | 15 | — |

### 2.6 值班管理

| 功能 | 说明 |
|---|---|
| 按地点切换 | 每个馆藏地点独立一套值班表 |
| 每周值班 | 周一至周日开关，作为默认规则 |
| 日历单日覆盖 | 点某一天临时切换「有人值班 / 无人值班」，灰点标记被覆盖的日期 |
| 作用 | 读者的取书日期、还书日期只能选有人值班的日子；云端二次校验 |
| 保存 | 有改动才可保存，避免误触 |

### 2.7 数据统计

时间口径两个 Tab 共用：近 7 / 30 / 90 天，或**自定义起止日期**（结束 ≤ 今天、开始 ≥ 两年前、跨度 ≤ 731 天；越界自动收敛并提示）。

**用户统计**

- 概览 4 卡：注册用户、有效借书证、区间新增、人均借阅
- 按馆藏地点分布、按角色分布、按借阅次数分档（0 / 1–2 / 3–5 / 6+）
- 新增用户趋势（≤31 天按天、≤120 天按周、更长按月）
- 借阅排行 TOP 20
- CSV 导出：昵称、角色、借书证状态、归属馆藏、手机号（中间四位脱敏）、注册时间、累计借阅、区间借阅、最近借阅

**书籍统计**

- 概览 4 卡：书籍种类、馆藏总册、在架可借、区间新增
- 分类分布、馆藏地点分布、评分分布（1–5 星）
- 新增书籍趋势（同样的按天 / 周 / 月降精度）
- 借阅热度 TOP 20
- 滞销书：从未被借且上架超 30 天
- CSV 导出：书名、作者、ISBN、分类、出版社、出版年、馆藏总册、在架册数、累计借阅、平均评分、评论数、上架时间

导出文件带 BOM，Excel 直接打开不乱码；文件名带起止日期，多次导出不撞名；上限 3000 行。

### 2.8 通知群发

| 功能 | 说明 |
|---|---|
| 发送范围 | 全部用户 / 按馆藏地点 |
| 内容 | 标题 ≤30 字、正文 ≤200 字、点击跳转页面（借阅管理 / 我的借阅 / 书评 / 首页等） |
| 送达 | 单次最多 500 人；公告类不受用户通知开关限制 |
| 发送记录 | 标题、正文、送达人数、发送人、时间、范围，倒序分页 |

### 2.9 书评审核

| 功能 | 说明 |
|---|---|
| 筛选与搜索 | 全部 / 展示中 / 已隐藏；按评论内容搜索 |
| 回复 | ≤200 字，发送后通知作者 |
| 隐藏 / 恢复 | 隐藏后从书籍详情与书评列表消失，并**重算该书平均分与评价数** |
| 删除 | 物理删除，同样重算评分 |

## 3. 共用业务规则

| 规则 | 默认 | 可配置 | 校验位置 |
|---|---|---|---|
| 借期 | 30 天 | 馆藏设置 | 云函数（确认借出时） |
| 同时借阅上限 | 3 本 | 馆藏设置 | 云函数（提交申请时） |
| 续借 | 1 次 × 15 天 | 馆藏设置 | 云函数 |
| 借书证 | 需审批，与馆藏地点绑定 | — | 云函数 |
| 值班日 | 默认全不开放，需管理员按周勾选 | 值班管理 | 云函数 + 前端日历 |
| 到期提醒 | 每天 09:00 定时扫描 | 定时触发器 | `notify` 云函数 |
| 通知保留 | 90 天（定时清理） | — | `notify` 云函数 |
| 书评 | 一人一书一条，5–500 字 | — | 云函数 |
| 权限 | 所有管理动作在云函数内校验 `role=admin` | — | 全部云函数 |

## 5. 数据边界

| 集合 | 客户端权限 | 访问方式 |
|---|---|---|
| `books` | 所有用户可读 | 客户端直查（仅此一个） |
| `borrows` | 所有用户不可读写 | 云函数 `borrowManager` |
| `users` | 所有用户不可读写 | 云函数 `login` / `borrowManager` / `insightManager` |
| `settings` | 所有用户不可读写 | 云函数 `borrowManager` / `insightManager` 读写 |
| `reviews` / `notifications` / `todos` / `noticeLogs` | 所有用户不可读写 | 云函数 |

完整规则见仓库根目录 `database.rules.json`（权限唯一基准）。
